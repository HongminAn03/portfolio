# Portfolio

Personal portfolio website — Hongmin An, Computer Science @ Penn State.

## Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Deployment**: Vercel

## Features

- Custom animated cursor with pointer/drag states
- Sprite-animated character walking across the navbar
- Loading screen with animated progress bar
- Aurora background effect on hero section
- Horizontal project carousel with edge-locked navigation
- Draggable tech stack carousel
- Responsive layout

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
